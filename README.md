# Mi Ciclo, Mi Poder — demo

Sitio compilado de la app **Mi Ciclo, Mi Poder** con la asistente **Numa**.
Se publica solo para poder mostrarla desde el navegador.

**Verla:** https://xnod-proyectos.github.io/mi-ciclo-mi-poder/

servidor, no hay cuentas y no hay base de datos.

El código fuente vive en otro repositorio, privado.
